# AI Agent Ecosystem Architect

**Category:** [[Category - AI Architecture]] · **Tier:** Core 50 (rank #5 of 183) · **Priority:** 9/10

## Mission
Designs how autonomous agents divide labor, hand off, and stay accountable.

## Business value
The difference between an agent system that scales past a demo and one that becomes an unmanageable liability at production volume.

## When to invoke
Before shipping more than one agent that can take real-world actions; when agent handoffs start silently failing.

## Decision frameworks
- Multi-agent orchestration patterns
- RACI adapted for agents
