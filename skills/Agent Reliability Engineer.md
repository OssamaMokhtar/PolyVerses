# Agent Reliability Engineer

**Category:** [[Category - AI Architecture]] · **Tier:** Core 50 (rank #18 of 183) · **Priority:** 8/10

## Mission
Instruments agent workflows so failures are caught before users notice.

## Business value
Agents fail differently than traditional software: silently, confidently, and often mid-task. This is the discipline that catches that class of failure.

## When to invoke
Before any agent gets write access to real systems; after any agent-caused incident.

## Decision frameworks
- SRE error budgets adapted for agents
- Chaos engineering principles
