# Privacy Policy

**Status:** Draft — for prototype phase. Not a substitute for legal advice.

## Data We Collect

| Data | Purpose | Retention |
|------|---------|-----------|
| User profiles (product team accounts) | Authentication, access control | Per user; deletable on request |
| Agent run traces | Orchestration history, observability | Per run; retained for debugging and improvement |
| Prompt iterations | Prompt console history | Per user; deletable on request |
| Workflow data | Multi-agent workflow definitions | Per user/team; deletable on request |
| Usage analytics | Heatmap generation, product improvement | Aggregated, de-identified where possible |

## Data Storage

- Agent run traces and workflow data are stored in Firestore (prototype: development only).
- No data is shared with third parties except as required for LLM inference (Gemini API, server-side only).
- Product team data is business confidential and handled accordingly.

## Your Rights

Under applicable data protection laws, you have the right to:

- Access your data
- Correct inaccurate data
- Request deletion of your data (subject to audit trail retention requirements)
- Withdraw consent (where processing is consent-based)

## Contact

For privacy inquiries, contact the maintainer.
